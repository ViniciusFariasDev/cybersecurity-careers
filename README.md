# Cybersecurity Careers

This repository documents the completion of a **Cybersecurity Careers** module, providing an overview of the main roles, responsibilities, and career paths within the cybersecurity industry.

The module focuses on helping learners understand where they may fit within cybersecurity based on interests, skills, and long-term goals.

---

## 📌 Module Overview

Cybersecurity offers a wide range of career paths, from defending organisations against cyber threats to actively testing systems through ethical hacking.

This module introduces both **defensive (Blue Team)** and **offensive (Red Team)** roles and explains how professionals contribute to protecting digital environments.

---

## 🧠 Topics Covered

- Introduction to cybersecurity careers
- Security Analyst (Blue Team)
- Security Engineering
- Penetration Testing (Ethical Hacking)
- Career progression in cybersecurity
- Entry-level and advanced role paths
- Skills and traits for cybersecurity professionals

---

## 🛡 Defensive Security Roles

- Security Analyst
- Incident Responder
- Threat Hunter
- Malware Analyst

Responsibilities include monitoring, investigation, detection, and response to security incidents.

---

## 🔴 Offensive Security Roles

- Penetration Tester
- Red Team Operator
- Application and Network Testing
- Adversary simulation

Responsibilities include identifying vulnerabilities by simulating real-world attacks in a controlled and authorised manner.
